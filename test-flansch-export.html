Flansch Export Debug Test

1. Schritt: Öffne die normale App

Öffne index.html im Browser

2. Schritt: Teste Flansch-Änderung

  1. Gebe Text ein: "ABC"
  2. Aktiviere Flansch-Checkbox
  3. Stelle Flansch-Länge auf z.B. 50 mm
  4. Öffne Browser DevTools (F12) → Konsole
  5. Führe folgende Code-Zeile aus:
console.log("Flansch-Länge in UI:", document.getElementById("flansch-len").value);
console.log("Flansch enabled:", document.getElementById("flansch-enabled").checked);
console.log("Clip Geo vertices count:", textGroup?.userData?.clipGeo?.attributes?.position?.count);

3. Schritt: Überprüfe exportierte OBJ

  1. Klicke "Download OBJ"
  2. Öffne die heruntergeladene .obj Datei in einem Text-Editor
  3. Suche nach "o Clip" (der Flansch ist Teil des Clips)
  4. Überprüfe die Koordinaten - die Flansch sollte von x₁ bis x₂ gehen
  5. Berechne die Länge: x₂ - x₁ sollte ≈ 50 mm sein

Ausführlicher Debug-Code

Kopiere diese Zeilen in die Konsole, um mehr Details zu sehen:

// Zeige Clip-Geo-Bounds
const clipGeo = textGroup?.userData?.clipGeo;
if (clipGeo) {
  clipGeo.computeBoundingBox();
  const bb = clipGeo.boundingBox;
  console.log("Clip Bounding Box:", bb);
  console.log("Clip width (X):", (bb.max.x - bb.min.x).toFixed(2), "mm");
  console.log("Flansch length sollte sein:", document.getElementById("flansch-len").value, "mm");
}

// Zeige alle Vertices des Clips
if (clipGeo?.attributes?.position) {
  const pos = clipGeo.attributes.position;
  console.log("Clip hat", pos.count, "Vertices");
  // Min/Max X-Koordinaten
  let minX = Infinity, maxX = -Infinity;
  for (let i = 0; i < pos.count; i++) {
    const x = pos.getX(i);
    if (x < minX) minX = x;
    if (x > maxX) maxX = x;
  }
  console.log("Min X:", minX.toFixed(2), "Max X:", maxX.toFixed(2));
  console.log("Clip width:", (maxX - minX).toFixed(2), "mm");
}
